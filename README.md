# Ellochka — интерпретатор на Zig

Реализация языка программирования `Ellochka` (автор Э.Г. Гаузер, 1999)
на языке Zig 0.16.0. MVP-версия без графики и файловых операторов.

## Сборка и запуск

```
zig build
zig build run -- examples/hello.ell
```

Или напрямую после сборки:

```
./zig-out/bin/ellochka examples/hello.ell
```

Если есть проблемы с русскими символами в консоли  chcp 65001

## Структура проекта

- `src/state.zig` — таблицы переменных, массивов, строк, режимы исполнения.
- `src/errors.zig` — единый набор ошибок парсинга и выполнения.
- `src/lexer.zig` — построчный лексер (токенизация одной строки).
- `src/expr.zig` — парсер и вычислитель арифметических выражений,
  математические функции (&SIN, &COS, &SQR и т.д.).
- `src/program.zig` — загрузка программы, таблица меток, адресация по
  номерам строк.
- `src/statement.zig` — разбор и выполнение операторов (MVP-подмножество).
- `src/main.zig` — точка входа, главный цикл интерпретатора.

## Реализовано в MVP

- Числовые переменные (A-Z), одномерные и двумерные массивы.
- Присваивание: `A=expr`, `A[i]=expr`, `A[i,j]=expr`,
  неявные циклы `A[]=expr`, `A[,]=expr`.
- Управляющие операторы: `GOTO`, `ESLI` (с условиями >>,<<,>=,<=,==,|=),
  `SLEP`, `RADI`/`GRDS`, `ORUP`/`ORDN`.
- Ввод/вывод (текстовый режим через ANSI): `LIST`, `VVOD`, `CLSC`,
  `CFON`, `CSIM`, `STRO`, `STLB`.
- Математические функции: `&RAN#`, `&SIN`, `&COS`, `&TAN`, `&ASN`, `&ACS`,
  `&ATN`, `&EXP`, `&LOG`, `&INT`, `&FRC`, `&ABS`, `&SGN`, `&SQR`.
- Метки (`@label`) и переходы по номеру строки или метке.
- Системные: `EXIT`, `STOP`, базовый `MEMC`.

## Отложено на следующую итерацию

- Графические операторы (`GRAF`, `PIXL`, `LINE`, `KRUG`, `PAIN`, `SBMP` и т.д.)
  — требуют графическую библиотеку (raylib).
- Файловые операторы (`READ`, `TYPE`, `GETF`/`PUTF`, `LENF`, `UDAL`, `PATH`,
  `FILE`, `FREE`).
- Строковые операции: присваивание строковых переменных, варианты
  присваивания `A:константа`, `A:$?[i]`, `A#$текст`, строковые функции
  (`%MID`, `%CHR`, `%DATE`, `%TIME`).
- `SIZE`, `UMEM`, `CURR` — управление размерами массивов в рантайме.
- `DOSC`, `KEYS`, `WAIT`, `DATA`, `MENU`.
- Математические операторы решения задач (`LIRA`, `POLI`, `DTRM`, `APRO`,
  `REAK`, `USER`, `TRAN`, `NTGR`).
- Календарный оператор `JULD`.
- Оставшиеся "прочие" операторы (`MINA`/`MAXA`/`SUMA`, `SORT`, `INCR`/`DECR`,
  `FIND`, `DLIN`).

## Известные технические долги

- `&RAN#` использует `std.crypto.random` — не воспроизводимо между запусками.
  Для тестируемости стоит добавить seed через аргумент командной строки.
- `execAssignment` в `statement.zig` пока не поддерживает варианты
  присваивания 4-6 (`:`, `#`) — только варианты 1-3 (`=`, `[]=`, `[,]=`).
